# Welcome to Visa For Lisa
***

## Task
The goal of this project is to help Galaxy Bank increase its personal
loan conversion rate by identifying which deposit customers are most likely 
to accept a loan if one is offered.
This project addresses the bank’s need to target the right customers, increase conversion, 
and reduce marketing cost

## Description
To solve the problem, we followed a complete data-science workflow:

Data Cleaning & Preparation
Exploratory Data Analysis (EDA)
Machine Learning Models 
  Baseline Model
  Multivariable Linear Regression
Insights & Business Impact

## Installation
Run pip install -r requirements.txt to install dependencies

## Usage
Open Jupyter Notebook
Load visaforlisa.ipynb
Run all cells
```
./my_project argument1 argument2
```
