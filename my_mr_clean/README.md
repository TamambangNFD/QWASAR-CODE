 Extracting an article from Wikipedia.

Cleaning the content.

Tokenizing the words.

Removing unimportant (stop) words.

Creating a frequency model.

Visualizing the data.

Data Retrieval: Used Wikipedia's API directly with requests (not the wikipedia package).

Content Extraction: Parsed the JSON response to extract the raw article text.

Tokenization: Split the content into words using regular expressions.

Normalization: Converted all tokens to lowercase for consistency.

Stop Word Removal: Filtered out common English stop words that do not carry semantic value.

Frequency Analysis: Counted how often each word appears.

Visualization: Plotted histograms using matplotlib to show most common words
