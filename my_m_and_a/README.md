# Welcome to My M And A

---

## Task

There are three different customers, but each one has customer information stored in a different, disorganized way

## Description

We have developed a script to combine the three different formats into one single standardised format

## Installation

Run `pip install -r requirements.txt`

## Usage

Uncomment lines at the end of `my_m_and_a.py`, and run the script. It will automatically combine the changes into the db file
