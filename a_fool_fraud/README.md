# Welcome to A Fool Fraud
***

## Task
Analyze a credit card fraud dataset, clean it, and build baseline machine learning models to evaluate performance. 
The challenge is handling imbalanced data and ensuring reproducible experiments.

## Description
The pipeline loads the raw dataset, cleans and samples it for faster experimentation, 
then trains baseline models. Results are saved to disk for later comparison.

## Installation
pip install  required libraries

## Usage
Run the analysis and model training in Jupyter 
Outputs such as cleaned CSV files and results (baseline_results.pkl) are saved automatically.
```
./my_project argument1 argument2
```
